## 📌 Project Overview

**AI Next Word Prediction** is a Deep Learning-based Natural Language Processing (NLP) application that predicts the most probable next word from a user-provided text sequence.

The project leverages a **Long Short-Term Memory (LSTM)** neural network to learn contextual relationships between words and generate accurate next-word predictions. A modern Streamlit interface enables users to interact with the model in real time.
